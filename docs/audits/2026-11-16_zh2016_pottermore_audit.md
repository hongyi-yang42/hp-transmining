## 5. 与本仓现有 HP1 中文语料的比对

对照 `data/text_clean/hp1_zh_ch01–17`（2000 初版谱系 calibre 2019 电子版转写，排版归一后，印刷侧段为分母 n = 2,776）：

| 类别 | 段数 | 占比 |
|---|---|---|
| 逐字相同 | 1,187 | 42.8% |
| 仅标点微差 | 288 | 10.4% |
| 含文字差异（典型每段 1–3 字） | 1,097 | 39.5% |
| 切分边界差异 | 100 | 3.6% |
| 无 ≥0.80 对应段 | 104 | 3.7% |

EPUB 侧对称（n = 3,061）：逐字同 45.2%，无对应 6.5%（绝大多数为对话/叙述合分差异，非内容缺失）。

（v1 报告的 "82% 逐段相同" 为分母口径错误，已作废；以上为含完整分母的重算结果。）

**结论：同一译本（苏农）的两个不同文本状态（2016 数字修订态 vs 2000 初版谱系印刷态）——同译本、不同态、不得混用。** 对本仓 DE↔ZH 对齐与标注无影响。

## 6. 可用性判定

**有条件可用作七册平行语料库中文底本**，条件：

1. 入库标点归一化规则口径（半角？！、省略号/破折号、引号风格）在分句管线设计时定稿。
2. 版本字段按本报告精度登记（含 UNVERIFIED 项），不填猜测年份。
3. HP5 若涉及后十章译者风格研究，需 2003 印刷本锚点章逐字比对后再定。
4. 与 EN 底本（`hp_en_2015_pottermore_1-7.epub`，见 `docs/audits/2026-11-19_en2015_pottermore_audit.md`）同为 Pottermore 数字件 + calibre 转制，版本声明粒度对齐。

UNVERIFIED 清单：对 2016 原始发行件的逐字保真性；HP1 具体修订印次；HP3 数字态相对马氏印刷本有无进一步修订；HP2/4/6/7 印次内修订状态；HP5 2003/2009 态。
